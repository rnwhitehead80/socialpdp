# Next PDP experiments

A static prototype for testing Next product detail page changes with shoppers arriving from social ads or Google Shopping. It includes Test C as a baseline and 20 experiments. Use **Experiment set** to switch between experiments 1–10 and 11–20. **Shopper view** hides moderator controls, and **Reset to Test C** turns off all experiments.

Images and fonts are embedded in `index.html`. Product information, prices, delivery, stock and reviews use sample data. Open `index.html` in a browser for a local preview. The prototype runs without installation, a build step or a server.

## Publish to GitHub Pages

1. Extract the ZIP. Upload `index.html` and `README.md` to the top level of your repository and commit them to `main`. In GitHub's web interface, use **Add file → Upload files**.
2. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main** and **/(root)**, then save. If your default branch has a different name, use that branch.
4. After deployment finishes, return to **Settings → Pages** and select **Visit site**.
